## Selected work

| Project | What it does | Stack |
|---|---|---|
| **[STEM Expo — Scoring System](https://stxpo.netlify.app/)** | Judging console for a live competition. Judges authenticate, score teams against official rubrics, and results stay sealed until every assigned judge has submitted. Roster management, judge accounts, CSV export. | Supabase Auth, PostgreSQL, JavaScript |
| **[STEM Expo — Live Leaderboard](https://stxleaderboard.netlify.app/)** | The public companion to the console — a leaderboard that unseals a team's score the moment its last judge submits, and updates in realtime. Deliberately split from the scoring app so the private and public surfaces share a database but nothing else. | Supabase Realtime, PostgreSQL |
| **[STEM Development Foundation](https://nsil-sdf.netlify.app/)** | 13-page platform for a Nigerian STEM NGO. Four member types with separate multi-step registration flows, four role-scoped dashboards, and row-level security so members read only their own records. | Supabase, PostgreSQL, JavaScript, Netlify |
| **[MahaFarm](https://mahafarm.netlify.app/)** | AI-driven farm platform turning soil, water and weather data into operational decisions. | Web, ML |
| **[TMC Abuja](https://tmc-abuja.netlify.app/)** | Organisation site spanning three area councils — structure, excos and events, colour-coded so members can read it at a glance. | JavaScript, SPA |
