## Selected work

| Project | What it does | Stack |
|---|---|---|
| **[STEM Expo — Scoring System](https://stxpo.netlify.app/)** | Judging console for a live competition. Judges authenticate, score teams against the official rubric, and a team's result stays sealed until every assigned judge has submitted. Roster management, judge accounts, CSV export. | Supabase Auth, PostgreSQL, JavaScript |
| **[STEM Expo — Live Leaderboard](https://stxleaderboard.netlify.app/)** | The public companion — a leaderboard that unseals a team's score the moment its last judge submits, updating in realtime. Deliberately a separate deployment, so the public screen ships none of the judging code. | Supabase Realtime, PostgreSQL |
| **[Breakroom](https://github.com/abaaqi/BreakRoom)** | Kahoot-style multiplayer party games for distributed teams. Host on the big screen, players join from their phones with a room code. Scoring runs server-side, so the correct answer never reaches a client until results. | Node.js, Express, WebSockets, React |
| **[MahaFarm](https://mahafarm.netlify.app/)** | Full-stack precision-agriculture platform — field monitoring, irrigation automation, a disease-scan flow and a produce marketplace. React front end, Express/Mongo API, Docker Compose for the whole stack. | React, Vite, Express, MongoDB, Docker |
| **[STEM Development Foundation](https://nsil-sdf.netlify.app/)** | 13-page platform for a Nigerian STEM NGO. Four member types with separate multi-step registration flows, each routing to its own role-scoped dashboard. | JavaScript, Netlify |
